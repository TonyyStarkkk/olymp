# Олимп · Python с нуля

Интерактивный самоучитель для 9 класса. Цель подготовки — олимпиада через 8 недель.

## Открыть как обычный сайт

Адрес после успешной публикации: **https://tonyystarkkk.github.io/olymp/**.

Ученикам не нужны установка Python, терминал или аккаунт GitHub: достаточно открыть сайт, нажать «Начать первый урок» и писать код в редакторе.

Для владельца репозитория при первой публикации:

1. Открыть [Settings → Pages](https://github.com/TonyyStarkkk/olymp/settings/pages).
2. В разделе **Build and deployment → Source** выбрать **GitHub Actions**.
3. Открыть [Actions → Publish Olymp to GitHub Pages](https://github.com/TonyyStarkkk/olymp/actions/workflows/pages.yml). Если предыдущая попытка не прошла до включения Pages, нажать **Re-run all jobs**; либо запустить **Run workflow** на ветке `main`.
4. Дождаться зелёной отметки у задания **Publish the website**, затем открыть адрес сайта.

После первой настройки каждый push в `main` автоматически обновляет сайт. Сборка выполняется с базовым путём `/olymp/`, включая Python, worker, шрифты и иконку. Публикуются только файлы из `dist/`; локальные результаты учеников не отправляются в репозиторий. Прогресс на опубликованном сайте начнётся отдельно от локальной версии, поскольку браузер хранит данные по адресу сайта.

## Что реализовано

- Все 8 недель доступны, без незаполненных разделов.
- Полный учебный маршрут: 40 занятий, 120 задач, 40 вопросов на понимание.
- Вторая неделя: сравнения, if / else, elif, and / or / not и задача D «Модный шрифт» из PDF. В задаче D проверяются все 10 цифр, рисунки сверены со схемой и примерами условия.
- Третья неделя: for / range, сумма и счётчик, while, точные расчёты объёма памяти и полная задача B из PDF (страницы 14–15), включая три исходных примера.
- Четвёртая неделя: строки, списки, словари, названия чисел и полная задача E о произношении года из PDF (страницы 4–5). Справочник английских слов встроен в уроки; проверяются все 127 годов 1900–2026.
- Пятая неделя: перебор, окна в строке, устранение повторов и задача A «Ленивые пароли» (страницы 10 и 12 PDF). Интерактивная схема поясняет направления; все десять допустимых длин сверены с независимым перебором по координатам клавиш.
- Шестая неделя: min / max, соседние пары, разделители, оценка скорости и полная задача C о разноцветных кубиках (страницы 13 и 16 PDF). Схема строит цепочки для небольших запасов; формула и схема сверены с независимым полным поиском для всех 343 наборов от 0 до 6 кубиков каждого цвета. Проверяются нулевые и миллиардные количества.
- Седьмая неделя: множества, поиск ближайшего большего числа, префиксы, полная задача F «Вирусные числа» (страницы 7–8 PDF) и стратегия первого тура. F обрабатывает ровно десять запросов до 9999999999 без перебора промежутка чисел; проверены все 10000 малых входов и 415 больших/граничных случаев независимым поиском по цифрам. Примеры F в тренажёре учебные, не взяты из PDF.
- Восьмая неделя: повторение базы, исправление ошибок, подбор проверок, повторение A–F и подготовка к старту. Тесты различают допустимость и оптимальность ответа, проверяют пустые данные, отрицательные числа и независимость запросов.
- Генеральная репетиция на 180 минут: те же A–F, но с пустыми редакторами и справочными материалами из условий. Она хранится отдельно от первого тура и не заменяет его результаты. После каждого тура можно выбрать причину затруднения и записать план повторения; заметки сохраняются и включаются в экспорт.
- Отдельный тренировочный тур на 180 минут: шесть знакомых задач A–F, сохранение времени начала, черновиков и принятых решений, автоматическое завершение, ранний финиш, разборы и JSON-экспорт. Открывается через меню или седьмую неделю.
- Прогресс отображается по каждой неделе и по всем доступным урокам; сохранения первых семи недель совместимы без переноса.
- Теория с примерами, задания с нуля и на исправление кода, три уровня подсказок, разборы.
- Настоящий Python 3 через Pyodide в Web Worker. Ввод, вывод, сравнение с тестами, понятные объяснения ошибок.
- Кнопка остановки, ограничение времени выполнения (5 секунд на тест) и объёма вывода (24 КБ).
- Сохранение черновиков, входных данных, прогресса и использованных подсказок в localStorage.
- Отдельный учёт самостоятельных решений и решений с помощью. Занятие завершено после трёх задач и вопроса.
- Экспорт результатов и кода в JSON, памятка Python, адаптивный интерфейс.

## Запуск

Требуется Node.js 22.12+ (проверено на 24.19) и npm.

```sh
cd /workspace/olymp
npm ci --cache /tmp/olymp-npm-cache
npm run dev -- --port 5173
```

Путь к кешу нужен в этой облачной среде, где домашний каталог недоступен для записи. На обычном компьютере можно выполнить `npm ci`.

`postinstall` копирует файлы Pyodide из npm-пакета в `public/python/`. Они не хранятся в Git, но включаются в сборку. Если зависимости были установлены с `--ignore-scripts`, отдельно выполните `npm run postinstall`.

Python, стандартная библиотека и шрифты раздаются самим приложением, без CDN и внешних API. Первый запуск Python загружает runtime; последующие запуски внутри того же задания используют готовый worker. Точное время загрузки зависит от устройства. Программа ученика выполняется в браузере, не на сервере.

## Сборка и проверка

```sh
npm run build
npm run preview -- --port 4173
```

Статический сайт находится в `dist/`. Публиковать нужно всю папку, включая `python/` и файлы `.wasm`, `.mjs`, `.zip`. Навигация использует hash, серверное перенаправление маршрутов не нужно. По умолчанию приложение собирается для корня сайта; workflow GitHub Pages передаёт `--base=/olymp/`.

Сквозные тесты используют установленный Chromium и Python Playwright:

```sh
python3 -m pip install -r tests/requirements.txt
# Если системного Chromium нет:
python3 -m playwright install chromium
npm run build
npm run test:e2e
node --experimental-strip-types tests/contest-state.mjs
```

В текущей среде Chromium и Playwright уже доступны. Тесты сами запускают preview на порту 4173 и завершают его. `BROWSER_PATH` позволяет указать Chromium, `OLYMP_TEST_URL` — проверить уже работающий сервер. Снимки экрана и журнал сохраняются в игнорируемую папку `test-results/`.

Дополнительно проверяются граничные случаи условий, геометрия всех десяти цифр задачи D, все 5120 допустимых входов задачи B в CPython, все 127 годов задачи E и её шесть исходных примеров, геометрия маршрутов и все длины задачи A, полный поиск малых цепочек задачи C и её три исходных примера, независимый поиск преемников для F, сохранения первых семи недель и переход к продолжению курса. Проверяются все эталонные решения в CPython и реальном браузерном Python, ошибки, неправильные ответы, ввод, остановка, таймаут, предел вывода, восстановление после ошибок, подсказки, сохранение и экспорт, мобильная навигация, независимые результаты двух туров, пустые редакторы финальной попытки, заметки и их экспорт, таймер при перезагрузке и уходе со страницы, запрет поздних отправок, завершение/экспорт/новая попытка, сбой загрузки Python и повреждённый localStorage.

## Педагогические правила

Переход между уроками свободный: ученик может вернуться к нужной теме. Просмотр страницы не повышает прогресс. Успех по задаче фиксируется только после прохождения всех её тестов, включая дополнительные входные данные. Подсказки учитываются на момент первого успешного решения. Позднее обращение к разбору не меняет уже полученную отметку.

Тесты первых упражнений без ввода проверяют результат; они не доказывают, что ученик использовал переменные или понимает код. Для этого предусмотрены вопросы и последующие задания с переменными входными данными. Проверка пробелов строгая, завершающие переводы строк игнорируются. Все тесты в этом прототипе учебные, это не официальная система оценивания олимпиады.

## Границы первой версии

Нет аккаунтов, синхронизации между устройствами, импорта прогресса, кабинета преподавателя и официальной системы оценивания с частичными баллами. Данные удаляются при очистке данных сайта. JSON-экспорт предназначен для сохранения и просмотра результатов. Работа полностью без сети после закрытия браузера не гарантируется: service worker пока не реализован.

Web Worker отделяет выполнение от интерфейса, но не является серверной песочницей для недоверенного многопользовательского кода. У браузерного Python доступны браузерные возможности в рамках origin приложения. На этом origin нельзя размещать секреты или административные сессии. Время и вывод ограничены; отдельной жёсткой квоты памяти в этой версии нет.

Тренировочный тур использует знакомые задачи и учебные проверки. Это самопроверка: время основано на часах устройства, результаты хранятся локально, защиты от изменения данных и подглядывания в уроки нет. Следует вести попытку в одной вкладке. Новая попытка заменяет предыдущую только в выбранном режиме после подтверждения; перед этим можно скачать результат вместе с заметками. Первая репетиция и генеральная сохраняются раздельно. Генеральная повторяет знакомый набор, а не предлагает новые неизвестные задачи. Уроки и их прогресс сохраняются отдельно.

После прохождения курса: закончить генеральную репетицию, разобрать конкретные ошибки и повторить слабые темы. Счётчик прогресса отражает уроки и упражнения; результаты туров учитываются отдельно. Освоение знакомого набора не гарантирует результат на новой олимпиаде.
